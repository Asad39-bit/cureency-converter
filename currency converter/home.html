About The Project

This Currency Converter is a modern web application that allows users to check live exchange rates for various currencies around the world and convert them between them.

The aim of this project is to provide a simple, fast, and user-friendly interface so that anyone can easily find accurate conversion rates. It uses a responsive design so it works well on both mobile and desktop.
